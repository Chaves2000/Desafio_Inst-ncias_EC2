# Desafio AWS - Gerenciando Instâncias EC2

## 📌 Descrição
Este desafio teve como objetivo aplicar conceitos de computação em nuvem utilizando serviços da AWS, realizando integrações entre armazenamento, processamento e banco de dados.

O diagrama da arquitetura foi desenvolvido utilizando o Draw.io para representar o fluxo da aplicação.

---

## 🏗️ Arquitetura do Projeto

O fluxo do projeto funciona da seguinte maneira:

- Upload de arquivo utilizando AWS CLI;
- Armazenamento do arquivo no Amazon S3;
- Disparo automático de evento (Trigger);
- Execução da função AWS Lambda;
- Armazenamento das informações no DynamoDB.
